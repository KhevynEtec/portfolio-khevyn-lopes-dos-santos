# 🎨 Manipulação de Estruturas de Dados em Python

## 📝 Descrição do Projeto
Este projeto explora o processamento de dados complexos através da manipulação de **listas, tuplas e dicionários** em Python. O foco principal é o uso de **loops aninhados de múltiplos níveis** para realizar transformações em matrizes de imagens (pixels RGB) e sequências musicais.

O sistema foi desenvolvido para resolver três desafios principais de lógica de programação:
*   **Processamento de Imagens (Emojis):** Implementação de um motor que percorre uma grade de 5x5 pixels, identificando cores específicas e aplicando "filtros de sombra" matemáticos (redução de 50% no brilho).
*   **Engenharia de Áudio (Matrizes Musicais):** Algoritmo de transposição de matrizes 2x2 para inversão de frequências sonoras em uma biblioteca musical.
*   **Integração de Estruturas:** Desenvolvimento de uma "Playlist de Imagens" que combina dicionários, listas e tuplas com métodos avançados de manipulação.

## 🚀 Tecnologias Utilizadas
*   **Linguagem:** Python 3.10+
*   **Estruturas de Dados:** 
    *   **Dicionários:** Para armazenamento de metadados e grades.
    *   **Listas de Listas:** Para representação de matrizes (pixels e notas).
    *   **Tuplas:** Para armazenamento imutável de valores RGB.
*   **Conceitos:** Loops aninhados (3 níveis), imutabilidade de dados e transposição de matrizes.

## 📊 Resultados e Aprendizados
O desenvolvimento destes algoritmos proporcionou o domínio técnico sobre:
*   **Transformação de Dados:** Aprendi a gerenciar a imutabilidade das tuplas criando novas instâncias durante o processamento de filtros.
*   **Navegação Complexa:** Implementação eficiente de 3 níveis de iteração (Lote -> Linha -> Pixel/Nota) para garantir a integridade da matriz.
*   **Métodos Integrados:** Aplicação prática de métodos como `.update()`, `.items()`, `.append()` e `.keys()` para manipulação dinâmica de coleções.
