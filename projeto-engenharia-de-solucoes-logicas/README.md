# 📊 Sistema de Triagem e Validação de Dados (Fluxograma e Pseudocódigo)

## 📝 Descrição do Projeto
Este projeto apresenta a modelagem lógica de um sistema de triagem e validação de dados, estruturado através de diagramas de fluxo e representações em pseudocódigo. fO objetivo principal é estabelecer um pipeline de decisão que valide entradas de usuários e aplique filtros baseados em parâmetros técnicos e demográficos.

Desenvolvido como parte do meu portfólio técnico, o sistema processa variáveis específicas para direcionar o fluxo de atendimento ou processamento de dados. A lógica abrange desde a validação inicial do dado até a finalização do processo (FIM), garantindo que cada etapa siga critérios rigorosos de decisão.

## 🚀 Tecnologias e Conceitos Utilizados
**Modelagem de Processos:** Estruturação de fluxogramas para visualização de decisões lógicas.
**Lógica de Programação:** Implementação de estruturas condicionais (SIM/NÃO) e loops de repetição.
**Algoritmos em Pseudocódigo:** Definição de passos computacionais para manipulação de variáveis.
**Parâmetros Técnicos:** Gerenciamento de variáveis como indicadores de pressão ou idade.

## 📊 Estrutura da Lógica e Resultados
O projeto demonstra a eficácia na organização de fluxos complexos, tratando diferentes cenários de entrada:

**Validação de Integridade:** O sistema inicia com a função "Valida dado", garantindo que a informação de entrada seja consistente.
**Filtros Condicionais:** Aplicação de regras baseadas em valores como $VA-80$ e limites de controle como $Don=10$.
**Segmentação de Dados:** Utilização de critérios como idade (ex: `Idade 65`) para ramificação do atendimento.
**Estrutura de Repetição:** Presença de comandos de controle como `WH` (While) e encerramento de processos.
